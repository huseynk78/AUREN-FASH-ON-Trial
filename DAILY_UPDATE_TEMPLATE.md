# Daily three-line update

Copy this format each day and replace the brackets:

```text
Done: [completed work and the PR/commit link]
Next: [the concrete next work item]
Blocked: [blocker, or “None”]
```

Example:

```text
Done: Added SQLite schema, seeded products, and admin order search in PR #4; reviewed the mobile order-form PR with two validation comments.
Next: Connect status changes to notification records and test export on a phone.
Blocked: None.
```
